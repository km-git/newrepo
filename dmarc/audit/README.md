Workspace inventory for the deliverability toolkit. `dmarc audit inventory`
writes `dmarc-inventory.json` (tool name, version, license, last-update) and
creates the six findings tables. Primary scanners: pip-audit plus the Mend
Bolt GitHub App. No paid SaaS. This module does not grade "security posture";
it lists the OSS mosaic so operators can see what they run.
